# HelpDesk Pro — Service Desk & Issue Tracking SaaS

Aplicação corporativa de Service Desk e Issue Tracking construída com foco em práticas avançadas de engenharia de software fullstack.

## Stack Tecnológica

- **Backend**: PHP 8.4+ / Laravel 12+, MySQL 8+, Redis, Laravel Sanctum, Pest PHP, Larastan / PHPStan, Laravel Pint.
- **Frontend**: React 19, TypeScript, Vite, TanStack Query, Zustand, Axios, React Hook Form, Zod, Vitest.
- **Infraestrutura**: Docker & Docker Compose (Nginx, PHP-FPM, MySQL 8, Redis, Queue Worker).

## Estrutura do Repositório

```text
├── backend/            # Aplicação Laravel 12 REST API
├── frontend/           # Aplicação React 19 + TypeScript + Vite
├── docker/             # Configurações de contêineres e Nginx
├── docker-compose.yml  # Orquestração local do ambiente
└── README.md
```
